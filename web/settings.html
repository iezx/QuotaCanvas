配置前准备

  • 拥有一个已激活、DNS 由 Cloudflare 托管的 Zone；选择一个尚未被其他 DNS 记录或 Access 应用占用的完整子域名。
  • 先在 Cloudflare 完成 Zero Trust 初始化，并配置可用的登录方式（例如邮箱验证码或身份提供商）。本页面不会修改账户级登录方式。
  • 在运行面板的电脑上安装 cloudflared；允许它向 Cloudflare 发起 TCP 或 UDP 7844 出站连接，VPN 或防火墙也需要放行。
  • 在 Cloudflare「我的个人资料 → API Tokens」创建自定义用户 API Token，添加下面的权限，并分别设置账号和区域资源范围：
  • Zone → Zone → Read
  • Zone → DNS → Edit（包含 DNS 读取；Zone 资源范围须包含此域名所属区域）
  • Account → Cloudflare Tunnel → Edit
  • Account → Access: Apps and Policies → Edit
  • Account → Access: Organizations → Read

如果 Cloudflare 界面把 Access: Apps 和 Access: Policies 分开列出，请分别选择编辑；组织权限可能显示为 Access: Organizations, Identity Providers, and Groups。DNS 必须选择 Zone → DNS，不是账号级的 DNS 设置。

在「Account Resources」包含域名所属账户，在「Zone Resources」包含域名所属 Zone；检查 Token 有效期、IP 限制和创建者的账户权限。系统会自动识别 Zone、账户与 Zero Trust 团队。检查主要验证读取和配置，不能保证所有写入权限有效；点击启用时才创建或修改本系统专用的 Access、Tunnel 和 DNS 记录。Token 只保存在服务器，不会回显。

参考 Cloudflare 官方文档：Tunnel API 配置 · 创建 API Token · 网络连接检查
